04. 核心功能與操作流程
1. 首頁： 顯示專題名稱、掃描按鈕及植物收藏入口。
2. 掃描頁： 開啟相機，提示使用者對準紙本植物圖鑑卡。
3. AR 植物資訊： 辨識成功後，自動顯示跟隨圖卡的 2D 資訊面板，內容包含植物名稱、外觀特徵及生長環境。
4. 徽章解鎖： 首次成功辨識後自動解鎖；再次掃描不重複增加進度。
5. 植物收藏頁： 五種植物卡片一開始全部顯示，未解鎖項目以灰階呈現，解鎖後可查看植物介紹。
05. 已確認的設計限制
- 使用 Android 手機作為主要測試平台。
- 使用紙本圖鑑卡作為 Vuforia Image Target。

- MVP 不包含問答測驗及多人連線。
